Project Overview

This project provides a secure authentication mechanism for a desktop application. It uses randomly generated security tokens, SHA-256 hashing, daily passkey verification, and hardware-based license activation.

🛠️ Technologies Used
Python
Tkinter – GUI
SHA-256 – Hashing
UUID – Hardware identification
Random & String – Security token generation
File Handling – Authentication and license storage
✨ Key Features
Daily security token generation
6-digit authentication passkey
SHA-256 based passkey calculation
Daily authentication verification
Permanent license activation
Hardware-based license verification
User-friendly Tkinter interface
Authentication success/failure messages
🎯 Objective

To develop a secure desktop authentication system that provides controlled access using passkeys, hashing, and device-based license verification.
